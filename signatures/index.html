Email Signature

Apple Mail (macOS)

  1. Mail › Settings › Signatures, pick the account, hit +.
  2. Uncheck Always match my default message font — leave it on and Mail flattens the tag.
  3. Click into the signature box, select everything already there, and paste.
  4. Quit and reopen Mail once so it rewrites its signature cache.

Gmail (web)

  1. Settings › See all settings › General › Signature.
  2. Create or open the signature, select all inside the box, paste.
  3. Scroll down and Save Changes — Gmail discards the box if you navigate away.

Gmail (iOS / Android)

  1. The mobile app can’t hold an image signature of its own.
  2. Set Mobile Signature to empty in the app, and Gmail falls back to the web signature above on everything you send.

Outlook

  1. Paste into Signatures › New. Outlook shows the first frame of a GIF and never animates — the tag is built so frame one is the finished art.
